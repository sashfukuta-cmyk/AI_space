# AI_space — 動画編集のWebアプリ

ブラウザ上で動画を読み込み、編集し、保存できるWebアプリを目指すプロジェクトです。
初心者でも使いやすい画面で、簡単な動画編集ができるようにします。

## 最初に目指す機能

- 動画ファイルの読み込み
- 読み込んだ動画のプレビュー再生
- 動画の開始位置と終了位置を指定するトリミング
- 編集した動画の書き出しとダウンロード

## 将来追加したい機能

- 複数の動画の結合
- テロップや字幕の追加
- BGMの追加と音量調整
- 動画の縦横比の変更
